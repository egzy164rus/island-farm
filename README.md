# Островная ферма — PWA

Мобильный фермерский симулятор, который можно установить на Android и iPhone/iPad.

## Игра

- Локально: `python3 -m http.server 8000`, затем откройте `http://localhost:8000`.
- Онлайн: после публикации откройте HTTPS-адрес сайта на телефоне.
- Android/Chrome: меню браузера или ⚙ Настройки в игре → **Установить приложение**.
- iPhone/iPad: Safari → **Поделиться** → **На экран Домой**.

Первый запуск должен быть онлайн, чтобы загрузить оболочку и зарегистрировать Service Worker. После этого оболочка доступна офлайн; игровой прогресс хранится в localStorage браузера.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите содержимое этой папки в ветку `main`.
2. В репозитории откройте **Settings → Pages** и выберите источник публикации **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт после push в `main`. Адрес Pages указан в **Settings → Pages** и в результате workflow.
4. Откройте адрес в телефоне по HTTPS, запустите игру один раз и установите её из браузера.

Все ссылки, manifest и Service Worker используют относительные пути, поэтому проект работает и на адресе вида `username.github.io/repository/`.
