ОСТРОВНАЯ ФЕРМА — PWA

Запуск для проверки на компьютере
1. Распакуйте архив и откройте папку farm-game в терминале.
2. Выполните: python3 -m http.server 8000
3. Перейдите на http://localhost:8000

Публикация и установка
Репозиторий подготовлен для GitHub Pages: workflow находится в .github/workflows/pages.yml. Для публикации загрузите эту папку в репозиторий, в Settings → Pages выберите GitHub Actions и дождитесь завершения workflow.

Установка на Android
1. Откройте опубликованный HTTPS-адрес (localhost подходит только для локальной проверки).
2. Откройте адрес игры в Chrome и дождитесь первой загрузки.
3. ⚙ Настройки → «Установить приложение» или меню ⋮ → «Установить приложение».

iPhone/iPad: откройте сайт в Safari → «Поделиться» → «На экран Домой».
После первой загрузки оболочка игры и значки доступны офлайн. Прогресс сохраняется в браузере этого устройства.

Проверка макетов
До PWA-обновления проверялись реальные запуски Chromium на ширине 320, 360, 390, 430 и 768 px: стартовый экран, ферма, склад, рынок и отображение кошелька в открытой панели.
